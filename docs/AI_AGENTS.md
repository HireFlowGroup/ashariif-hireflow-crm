# HireFlow AI Agents

## 1. Sales Agent

-   Zoekt nieuwe bedrijven
-   Prioriteert leads
-   Schrijft acquisitiemails
-   Plant follow-ups

## 2. Recruiter Agent

-   Analyseert vacatures
-   Zoekt kandidaten
-   Matcht kandidaten
-   Genereert interviewvragen

## 3. Research Agent

-   Onderzoekt bedrijven
-   Verrijkt CRM-data
-   Analyseert markten
-   Signaleert kansen

## 4. Operations Agent

-   Dagplanning
-   Taken beheren
-   KPI-overzicht
-   Workflowbewaking

## Gezamenlijke regels

-   Werken uitsluitend via tools
-   Geen directe SQL
-   Bevestiging voor risicovolle acties
-   Alle acties worden gelogd
